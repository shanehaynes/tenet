Tenet

Typed tests for AI policies

Shane Haynes · MGT 409 · Fall 2026

The problem

A team writes a policy for its AI agent. Nobody can say whether the agent follows it.

  • A rule that holds when asked politely but folds under claimed authority
  • A threshold the agent follows that is not the one the policy states
  • "Be candid" that depends on how the question is phrased
  • Two rules that point opposite ways, with nothing saying which wins
  • A rule whose kind was never decided

Today: nothing, a generic benchmark, or ten ad hoc prompts. Pass/fail cannot see any of these.

What is new

The agents

Plain code calls each narrow agent in turn; no agent calls another. Every call goes through one wrapper that logs tokens and cost and enforces the budgets.
