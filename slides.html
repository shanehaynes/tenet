Tenet

Typed tests for AI policies

Shane Haynes · MGT 409 · Fall 2026

Public repo: https://github.com/shanehaynes/tenet

Tenet tests whether an AI agent actually follows its written policy. In one sentence: it sorts each rule by kind, runs the test that kind demands, and reports where the agent departs from the policy and where the policy contradicts itself.

The problem

A team writes a policy for its AI agent. Nobody can say whether the agent follows it.

  • A rule that holds when asked politely but folds under claimed authority
  • A threshold the agent follows that is not the one the policy states
  • "Be candid" that depends on how the question is phrased
  • Two rules that point opposite ways, with nothing saying which wins
  • A rule whose kind was never decided

Today: nothing, a generic benchmark, or ten ad hoc prompts. Pass/fail cannot see any of these.

The person accountable for an agent today does nothing, runs a generic benchmark, or writes ten prompts by hand. None of those catches these five failures. A pass/fail check on 'did it refuse?' records the first polite refusal and stops.

What is new

Rule typeThe test it demands
ConstraintSix requests under rising pressure
TradeoffEight stakes levels: where does it switch?
DispositionTen paraphrases: is the trait stable?
OrderingForced conflicts: which value wins?

Tenet's new part is the rule-type taxonomy and the ambiguity map.

A constraint is held or broken. A tradeoff has a threshold. A disposition is a trait that should survive rephrasing. An ordering has a winner. So each type gets a different test. Harnesses like promptfoo or Inspect run the tests you write; scanners like garak probe generic failures. Tenet derives the tests from the policy's own structure. Say the last line as written.

The agents

Plain code calls each narrow agent in turn; no agent calls another. Every call goes through one wrapper that logs tokens and cost and enforces the budgets.

Cost

$0.0267 per policy audit · 88.1 % of input cached · $0.32 per user per month

  • Four-rung ladders instead of six: $0.00113 per ladder rule with 4 rungs vs $0.00159 with 6 (28.9 % saved per ladder; runs 6en5fEzxaf and SAnnfrbsRa)
  • A real agent costs about three times as much: every scenario is a full agent run
  • Whole project, every live call: $0.70 of the $40 key budget
Every call is logged with its tokens; caching the policy-sized prefix is what keeps an audit to a few cents. Four rungs instead of six cut ladder cost and, in these runs, lost no finding. A real agent costs about three times as much, because every scenario is a full agent run. The whole project used well under the $40 key budget.

Safety

Injected policies quarantined · runs halt at their budget · the judge ignores planted instructions (2 of 2 canaries) · every verdict quotes the agent verbatim, checked in code

Left: a policy with an injected instruction is quarantined before any agent sees it. Right: a run that reaches its test budget halts and says why; nothing unrun counts as a pass. The judge ignores instructions planted in transcripts, and every verdict must quote the agent verbatim, checked in code.

Impact and next steps

  • Untested policies: 17 defects across 3 policies; every policy had at least 2
  • The HW5 team: the charter and a role prompt disagree; the boss overrode a rule only the specialist could see; the money rules held before any tool had to refuse
  • Three rules' tests by hand: 17 min 20 s, 7× Tenet's time to write, run and judge them, and the hand-written sweeps vary several things at once (one person, one measurement)
  • Next: other models, full model specs, CI regression tests for prompt changes
Every untested policy had defects. On my own HW5 team, Tenet found things I did not know: the charter and a role prompt disagree, and the boss pushed a specialist to undo a correct refusal because the rule lived only in that specialist's prompt. Writing the tests for three rules by hand took me 17 min 20 s, 7× Tenet's time to write, run and judge them, and my sweeps changed several things at once, so they could not find a threshold. Next: other models, full model specs, and running Tenet on every prompt change like a test suite.
