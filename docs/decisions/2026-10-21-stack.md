# Stack

**Decision.** Next.js 16 App Router with TypeScript 5 and Tailwind 4, a framework-free core library under `src/core` used by both the route handlers and a `tsx` CLI, zod for every schema, the OpenAI SDK for model calls, vitest for unit and pipeline tests, Playwright for e2e and screenshots, and JSON files under `data/` for state. Shane's usual stack (Vite + Hono + Supabase) is not used.

**Why.** The PRD fixes this stack and the course's run rule favors one `npm install` and one `npm run dev` with no external services. Keeping the core free of Next means the CLI, the tests and the evidence scripts exercise exactly the code the app runs, and long live runs can go through the CLI without a dev server that might restart mid-run. Exact versions and the scaffold flags are in `2026-10-21-scaffold-and-versions.md`.
