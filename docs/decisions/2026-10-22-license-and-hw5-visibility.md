# MIT license; the HW5 repository stays private

**Decision (Shane, 2026-10-22).** Tenet's code is released under the MIT License (`LICENSE`, `package.json`), effective when the repository goes public for submission. The HW5 repository (`shanehaynes/Homework5`, which carries the `tenet-bridge` branch) stays private. The README, the report and the evidence notes describe the bridge and say it is available to course staff on request; they no longer link to it.

**Why.** A public repository with no license defaults to all rights reserved, which is not what a course submission meant to be cloned and run wants. Homework5 is graded homework, so it is not published. Nothing in Tenet needs it to run: the HW5 evidence (runs, transcripts with the agent's tool calls, ground truth) is archived in `docs/evidence/runs/`, and the HW5 sample cites the prompts it quotes.
