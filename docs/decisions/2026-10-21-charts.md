# Charts

**Decision.** Every chart (ladder strip, threshold chart, paraphrase dots, ambiguity map) is hand-rolled SVG in `src/core/report/`, rendered by the same React components in the app and in the standalone HTML export. Recharts is not used.

**Why.** The standalone report must open by double-click with no scripts and no network, which means static markup from `renderToStaticMarkup`. Recharts' responsive container renders nothing on the server. The charts are simple shapes with a few labels, so hand-written SVG is less code than configuring a library and looks identical on screen and in print.
