# Parallel lanes for independent work, outside the repo, mock only

**Decision.** From 2026-10-22, independent work may run as parallel agent lanes. Each lane gets its own git worktree and branch, placed in `~/projects/Tenet-lanes/<slug>`, outside the repository: inside it, the gate's `tsc` and `eslint .` would scan the copies. No `.env` sits above that folder, so a lane can only use the mock provider, and every live model call (the $40 key) stays with the orchestrating session. The orchestrator also owns `main`, the merge, the gate (tests and configs), the hot files (`STATUS.md`, `README.md`, `docs/evidence/**`, the report and the slides) and the HW5 backend. A lane may add a new test for its own code but never edit an existing one. Each lane reports its commit, files, gate result and what it did not verify; the orchestrator checks the commit on the remote, diffs the lane against the protected paths, reads the riskiest diff in full, merges into `main` and runs the gate there. The inventory is in `PARALLEL.md`.

**Why.** This replaces the single-writer rule in `2026-10-21-workflow.md` for work that splits cleanly by file. With two days left and the human scoring pending, three pieces could proceed at once without touching the same files: the blind scoring page (`feat/spotcheck-page`), the video script and policy-owner kit (`docs/video-and-owner-kit`), and a read-only audit before the repository goes public. Work that needs the key, the HW5 backend or the shared files stayed with the orchestrator.
