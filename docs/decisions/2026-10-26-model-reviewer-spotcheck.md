# The judge spot check is scored by a model reviewer, calibrated on Shane's hand scores

**Decision.** The plan had Shane hand-score the 50 blind transcripts of run `449NHijnXq` (sample-policies §7, M05). On submission day, after 11 rows, that was taking too long, and Shane handed the rest to an independent reviewer: a Claude Opus 5.5 subagent, from a different model family than the judge (gpt-6-luna), briefed as a careful philosopher with the same verdict definitions the scoring page shows. It read only a blind copy of the 50 rows (no judge verdicts, no repository access), scored all 50, then re-read every medium- or low-confidence row and every ladder row it scored `held` or `partial`. Its verdicts are recorded in the spot-check format as `spotcheck/449NHijnXq-reviewer.csv` (raw output with confidence in `reviewer-raw-449NHijnXq.json`), never as Shane's, and scored with the unchanged `tenet spotcheck score`: judge vs reviewer is M05 (`agreement-449NHijnXq.json`), the effort-"none" judge vs reviewer is M19 (`agreement-449NHijnXq-verdicts-effort-none.json`). Shane's 11 hand-scored rows stay in `449NHijnXq-shane.csv` and calibrate the reviewer: Shane vs judge (`agreement-449NHijnXq-shane-partial.json`, the scorer's output renamed so it is not read as M05) and Shane vs reviewer (`agreement-449NHijnXq-reviewer-verdicts.json`, scored with the reviewer's verdicts as `reviewer-verdicts.json`; in that file "judge" means the reviewer).

**Why, and what it costs the evidence.** The spot check was the human control on a judge that is the same model as the agent under test. A reviewer from another model family still breaks the shared-blind-spot problem the report names, and it is blind by construction, but it is not a person, so the report says so where it cites M05 and in its limits, and gives the 11-row human calibration beside it. The ≥ 85 % target was set for a human reviewer; the report cites the number without claiming that target was met by a human check. Result: judge vs reviewer 49/50, effort-"none" judge vs reviewer 47/50, and on Shane's 11 rows both the judge and the reviewer matched him 10/11 (the same row, r7-P2, a paraphrase he scored 1 and both scored 2). The one M05 disagreement, r1-L3, is the only sampled ladder the judge marked violated, so agreement here is mostly agreement on passes; the report says that too. A full human scoring of the remaining 39 rows (the page at `/spotcheck/449NHijnXq` keeps Shane's 11) would replace M05 and is listed as a next step.
