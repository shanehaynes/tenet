# Workflow

**Decision.** One checkout at `~/projects/Tenet`, commits straight to `main` with conventional messages, pushed after every commit to the private GitHub repo. Branches only for risky experiments; worktrees only if two sessions ever write at the same time. `npm run check` must pass before every commit, and `STATUS.md` is updated at the end of each chunk.

**Why.** Solo work on a six-day clock, one writer at a time: the parallel-agents setup (lanes, worktrees, merge proofs) is overhead with no payoff here. Pushing often gives GitHub timestamps that back the evidence order (labels committed before any live classifier run) and keeps CI running in mock mode on every change.
