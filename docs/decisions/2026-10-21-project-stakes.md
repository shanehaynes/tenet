# Project stakes

**Decision.** Tenet is built as a graded prototype, not a product: one builder (Shane) plus Claude sessions, five working days, local only, JSON on disk, no hosting and no accounts. The data is fictional sample policies, Shane's own HW5 prompts, a CC0 excerpt of the OpenAI Model Spec, and whatever text a user pastes, which goes to the model provider through the course's Portkey gateway. The repo becomes public before submission, so no key or private policy is ever committed, and the README says that pasted text leaves the machine.

**Why.** The rubric pays for a working end-to-end run, measured tokens, a safety defense shown working, a repo staff can run in ten minutes, and evidence behind every number (PLAN.md §0). Production concerns (auth, multi-user, a database, deployment) earn nothing and would cost days. The course key has a $40 budget, so live calls are deliberate and logged cumulatively.
